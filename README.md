# ИПЦ США: четыре ряда, 2019–2024

[Офлайн-отчёт](report.html) · [Превью](preview.png) · [Расчётный CSV](summary.csv)

В декабре 2024 года аренда основного жилья выросла больше остальных выбранных рядов как к январю 2019-го, так и к декабрю 2023-го.[3] Продукты для дома за весь период подорожали сильнее общего индекса, но годовой рост в декабре 2024-го был ниже общего.[1][2]

| Ряд | К январю 2019 | К декабрю 2023 |
|---|---:|---:|
| Все товары и услуги [1] | +25,38% | +2,89% |
| Продукты для дома [2] | +27,76% | +1,77% |
| Аренда основного жилья [3] | +31,50% | +4,27% |
| Электроэнергия [4] | +31,19% | +2,80% |

Месячные ряды CPI-U от BLS получены через FRED без сезонной корректировки и сглаживания.[1][2][3] Электроэнергия взята на тех же условиях.[4] Скрипт требует 84 последовательных месяца по каждому ряду (2018–2024), но показывает только январь 2019 — декабрь 2024. Индекс = `100 × CPI(t) / CPI(2019-01)`; год к году = `100 × (CPI(t) / CPI(t−12) − 1)`. CSV содержит 288 строк расчётных показателей; исходные CPI не сохраняются. CPI-U не описывает расходы конкретной семьи, а выбранные категории не складываются в общий индекс.

Для пересчёта нужен интернет; готовый HTML и тесты работают без сети.

```sh
python3 analyze.py
python3 -m unittest discover -s tests -v
```
